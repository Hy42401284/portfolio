# 黄艳 · 个人作品集

一个基于 Vue 3 + Vite 的个人作品集网站，聚焦产品规划、技术开发、硬件测试和工程文档能力，内容来自 `D:\hy\就业` 下的实际简历与项目素材。

## 技术栈

- Vue 3、Vue Router 4、Vite
- Tailwind CSS、PostCSS、原生响应式 CSS
- Vercel 单页应用部署配置

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

## 页面与内容

- 首页：个人介绍、技能标签和精选作品
- 作品集：按产品、技术、文档、硬件筛选
- 详情页：项目周期、角色、STAR 结构、图片墙和 MG 动画视频
- 关于我：教育背景、技能分组、获奖成果
- 证书：四六级及奖项材料，支持图片灯箱
- 联系方式：邮箱、GitHub 和前端校验的 mailto 表单

## 部署

项目已包含 `vercel.json`，构建命令为 `npm run build`，输出目录为 `dist`。接入 Vercel 项目后即可自动部署。
